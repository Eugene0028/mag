Реализации: HC-128 и Salsa20 — Bouncy Castle 1.86; Sosemanuk — eSTREAMJ 2.0.0; Rabbit — исходный код проекта по RFC 4503.

Что измеряется

  • Полная инициализация: новый объект, подготовка ключа и IV. Это общий этап для сравнения всех четырёх реализаций.
  • Подготовка ключа и установка IV: отдельные вызовы Rabbit и Sosemanuk. У HC-128 и Salsa20 API Bouncy Castle объединяет эти операции; раздельные значения отсутствуют.
  • Генерация потока: обработка заранее выделенного нулевого буфера через XOR и запись результата в готовый буфер. Состояние продолжается между операциями; подготовка ключа и IV выполняется до начала этого этапа.

Случайные входы, выделение буферов потока, файлы и консольный вывод находятся вне измеряемых интервалов. Общий исполнитель сохраняет результаты операций для наблюдаемости вычислений; это учебная методика без изоляции JVM, предоставляемой JMH.

Циклы серии делятся на число операций. Для потока медиана дополнительно делится на размер порции в байтах. Служебные затраты не вычитаются. Отдельные этапы не обязаны в сумме равняться полной инициализации: отличаются создание объектов и условия исполнения.
