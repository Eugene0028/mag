Формат и границы измерений

Секрет записывается как беззнаковое число старшим байтом вперёд, без знакового байта BigInteger, с нулями слева до ceil(bitLength(p) / 8) байт. Строки и hex не используются.

SHA3-256 использует стандартный MessageDigest Java 17. Его объект и провайдер подготавливаются до замеров; каждый digest обрабатывает целое сообщение, возвращает новый массив и сбрасывает состояние.

Измерены три математические операции MQV, кодирование секрета, хеширование готовых байтов, полное получение ключа из готового секрета и цепочка «вычисление секрета MQV + получение ключа».

Подготовка подгруппы, долговременных ключей и подписанного справочника, проверка подписи, подготовка входных обменов, файлы и вывод находятся вне измеренных интервалов. Полная цепочка в таблице начинается с уже подготовленных ключей и проверенных открытых данных.

Циклы серии делятся на число операций. Служебные затраты не вычитаются. Это учебное измерение одной JVM с влиянием JIT, сборки мусора и системного счётчика.
